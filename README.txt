QUICK SETUP
-----------
1. Open script.js.
2. Find:
      const WHATSAPP_NUMBER = "YOUR_WHATSAPP_NUMBER";
3. Replace it with your WhatsApp number using country code and digits only.
   India example:
      const WHATSAPP_NUMBER = "919876543210";
4. Save.
5. Upload the entire folder to a free static host.

FREE HOSTING OPTIONS
--------------------
- GitHub Pages
- Netlify
- Vercel

No server or database is required for this first version.

IMPORTANT
---------
- The website uses free Google Fonts and remote Unsplash images.
- Package prices are intentionally not hard-coded because no pricing was supplied.
- Replace the placeholder WhatsApp number before publishing.
- You can later add your domain, Google Analytics, enquiry storage, testimonials,
  real package prices, hotel pages, payment gateway, and an admin system.

DESIGN
------

deep navy + green.
